# 株式会社グリット Webサイト

## 構成
- `index.html` ホーム
- `services.html` 事業内容
- `strengths.html` 弊社の強み
- `company.html` 会社概要
- `recruit.html` 採用情報
- `contact.html` お問い合わせ
- `style.css` 共通CSS（スマートフォン対応）
- `script.js` モバイルメニュー
- `images/` サイトで使用する写真

GitHub Pagesでは、フォルダごとリポジトリのrootへアップロードしてください。


## 施工写真
